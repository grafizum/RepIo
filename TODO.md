## How agents use this file

1. A user prompt that asks for work on this project = a new task line here, added immediately.
   Write it as a checkbox line; on the following indented lines give it metadata: a status
   line (planned / in-progress / done), a priority line (low / medium / high / urgent), and a
   notes line with the user's request in short form.
2. Run the sync CLI after editing (config: `sync.config.json` in the repo root, git-ignored;
   see grafizum-dashboard/apps/sync-cli). It was recovered from `C:\Temp\sync.config.json` on
   the old Windows SSD and its WSL paths were rewritten for this machine. The sync run is what
   puts the task on the dashboard. Do NOT also create it via POST /v1/tasks — that would
   duplicate it.
3. Work is finished when the task is done AND the owner's next message is not a
   correction or error about it. Then: flip the checkbox, set the status line to review,
   sync again, and tell the owner in ONE short line ("✅ Ready for review: <title>").
   OWNER OVERRIDE (2026-09-25): the owner asked the agent to mark tasks DONE itself
   as each one is finished and verified, instead of stopping at review. So an agent
   may now write `status: done` for work it completed and checked (tests green), and
   say so in the same one-line report. Two limits survive the override: never mark
   done what was NOT verified (no "looks right" on a change only reasoned about,
   and anything needing a real phone check stops at review), and never mark a
   task done that the owner has not had a chance to complain about yet - if the
   owner's next message is a correction, rule 4 still applies.
   Dashboard-only tasks (the pre-2026-09-13 backlog) are closed the same way,
   through the dashboard API, and are still not copied into this file.
4. If the owner reports an error or asks for a change on a review task: uncheck it,
   set the status line back to in-progress, fix it, then go back to step 3.
5. Never delete a finished line. Never retitle a task after it synced (the dashboard
   matches by exact title; retitling looks like remove + add).
6. Legacy tasks that predate this file (2026-09-13) are dashboard-only. Do not copy them
   here — that would create duplicates.
