Change the theme and the icon with no restart

Owner, 2026-10-14: "can we change the theme and icon without needing to close and reopen the app manually". The cause was one argument. IconSwitchHelper wrote its component states with if (killApp) 0 else DONT_KILL_APP, and every caller took the 0 — PlatformUtils.applyAppIconChange left the parameter at its true default — so the system was told it may kill the process to apply the change, and it did. A "Restart Required" dialog existed to explain a restart the app was causing itself.
